Changes: the illustrations are scaled, positioned and embedded in the two original
workshop banners. Their colours and path artwork are unchanged. The surrounding layout,
typography, connectors and theme palettes are original to this profile.

Rationale: recognizable emoji artwork was explicitly requested by the owner. Local inline
SVG paths keep the banner self-contained, static and independent of emoji fonts, scripts,
CDNs or runtime dependencies. Attribution is linked from the profile footer and embedded
in each banner's metadata. No Twemoji JavaScript or font is used.


The ECG pulse, social-link glyphs, rectangular project cards and button layouts are original vector work. The earlier heart asset is retained only as historical source material; it is no longer displayed.
